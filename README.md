# Student Marks Prediction using Linear Regression

This repository analyzes the relationship between **Study Hours** and **Exam Marks** using Simple Linear Regression in Python.

## 📊 Project Files
- `Student_Marks_Correlation_Regression.py`: Python code for data analysis and modeling.
- `Student,Study_Hours,Exam_Marks.csv`: Dataset containing study hours and exam marks.
- `scatter_plot.png.png`: Visualization of raw data distribution.
- `regression_plot.png`: Visualization of fitted linear regression line.
- `requirements.txt`: Python dependencies required to run the script.

## 🛠️ Requirements & Installation
To run this project, make sure you have installed the required libraries:

pip install -r requirements.txt
